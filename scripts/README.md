# RAGFlow 脚本工具集

本目录包含 RAGFlow 项目的各种实用脚本和工具。

## 目录结构

```
scripts/
├── README.md          # 本文件
└── langfuse/          # Langfuse 集成相关工具
    ├── README.md      # Langfuse 工具说明
    └── test_connection.py  # Langfuse 连接测试脚本
```

## 工具分类

### 🔧 诊断和测试工具

- **`langfuse/test_connection.py`** - Langfuse 连接测试和诊断工具
  - 验证 Langfuse 配置
  - 测试网络连接
  - 诊断集成问题

### 🚀 使用指南

1. **运行脚本**：
   ```bash
   # 从项目根目录运行
   cd /path/to/ragflow
   python scripts/<category>/<script_name>.py
   ```

2. **查看帮助**：
   ```bash
   python scripts/<category>/<script_name>.py --help
   ```

3. **使用环境变量**：
   大多数脚本支持通过环境变量进行配置，具体请查看各脚本的文档。

## 开发规范

如果您需要添加新的脚本工具，请遵循以下规范：

### 📁 目录结构
- 按功能分类创建子目录（如 `langfuse/`, `database/`, `monitoring/` 等）
- 每个子目录包含 `README.md` 说明文件
- 脚本文件名使用下划线命名法（如 `test_connection.py`）

### 📝 代码规范
- 添加完整的文档字符串
- 使用类型提示
- 包含适当的错误处理
- 提供详细的日志输出
- 支持命令行参数和环境变量

### 📖 文档要求
- 每个脚本都应有清晰的使用说明
- 包含示例输出
- 提供故障排除指南
- 更新相关的 README 文件

### 🛠️ 测试要求
- 脚本应具有自测试能力
- 提供测试用例或测试数据
- 包含边界条件处理

## 贡献指南

1. **新增脚本**：
   - 在合适的子目录下创建脚本
   - 添加文档和使用说明
   - 更新相关 README 文件

2. **改进现有脚本**：
   - 保持向后兼容性
   - 更新文档和示例
   - 添加版本说明

3. **报告问题**：
   - 提供详细的错误信息
   - 包含运行环境信息

## 支持

如果您在使用脚本时遇到问题：

1. 查看脚本所在目录的 README 文件
2. 运行脚本的帮助命令
3. 检查项目的故障排除文档
4. 在项目仓库中提交 issue
